Tamaño de elementos

En CSS, podemos controlar el tamaño de los elementos utilizando propiedades como width (ancho) y height (alto). Estas propiedades nos permiten definir las dimensiones de los elementos en la página web.

  • width: Define el ancho del elemento.
  • height: Define el alto del elemento.

Unidades de medida

En CSS, podemos utilizar diferentes unidades de medida para definir el tamaño de los elementos. Algunas de las unidades más comunes son:

  • px: Píxeles, una unidad absoluta.
  • %: Porcentaje, relativo al contenedor padre.
  • em: Relativo al tamaño de fuente del elemento.
  • rem: Relativo al tamaño de fuente del elemento raíz.
  • vw: Unidades relativas al ancho de la ventana gráfica (viewport).
  • vh: Unidades relativas a la altura de la ventana gráfica (viewport).
