Seudo Clases

  • :hover - Se aplica cuando el usuario pasa el cursor sobre un elemento.
  • :active - Se aplica cuando un elemento está siendo activado (por ejemplo, cuando se hace clic en un enlace).
  • :focus - Se aplica cuando un elemento ha recibido el foco (por ejemplo, cuando se hace clic en un campo de formulario).
  • :first-child - Se aplica al primer hijo de un elemento.
  • :last-child - Se aplica al último hijo de un elemento.
  • :nth-child(n) - Se aplica al enésimo hijo de un elemento, donde n puede ser un número, una palabra clave o una fórmula.
  • :not(selector) - Se aplica a todos los elementos que no coinciden con el selector especificado.
