HTML Semántico

El HTML semántico se refiere al uso de etiquetas que tienen un significado claro y describen el contenido que contienen. Esto ayuda a los motores de búsqueda y a los lectores de pantalla a comprender mejor la estructura y el propósito del contenido. Algunos ejemplos de etiquetas semánticas son:

  • <header>: Define la cabecera de un documento o sección.
  • <nav>: Define un conjunto de enlaces de navegación.
  • <main>: Define el contenido principal del documento.
  • <section>: Define una sección genérica del documento.
  • <article>: Define un artículo independiente y autocontenido.
  • <aside>: Define contenido relacionado pero separado del contenido principal.
  • <footer>: Define el pie de página de un documento o sección.
