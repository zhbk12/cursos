Elementos de bloque en HTML

Los elementos de bloque son aquellos que ocupan todo el ancho disponible y comienzan en una nueva línea. Algunos ejemplos de elementos de bloque son:

  • <div>: Contenedor genérico para agrupar contenido.
  • <p>: Párrafo de texto.
  • <h1> a <h6>: Encabezados de diferentes niveles.
  • <ul> y <ol>: Listas no ordenadas y ordenadas.
  • <table>: Tabla de datos.
